# Flight Simulator

## Project Description
A terminal-based interactive flight simulation game that allows users to create and control multiple aircraft in a three-dimensional space, demonstrating basic flight mechanics and physics simulation.

## Key Features
- Create and manage multiple aircraft
- Dynamically adjust aircraft orientation (pitch, roll, yaw)
- Control aircraft throttle
- Real-time position tracking
- Turn-based gameplay
- Interactive command-line interface

## Technical Components
- Written in Java
- Object-oriented design
- Physics-based movement calculations
- User interaction through terminal menu system

## How to Run

### Compile
```bash
javac Plane.java FlightSim.java
```

### Run
```bash
java Main.java
```

## Learning Objectives
- Demonstrate object-oriented programming principles
- Simulate basic aircraft physics
- Practice user interface design
- Explore 3D movement and rotation algorithms
